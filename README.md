# Circle Packing Canvas Animation
Animated circle packing algorithm that grows non-overlapping circles from random seed positions.
## Features
- 200 circles starting at radius 1 and growing each frame until they touch
- Color by size from blue (small) to red (large) with multiple palette options
- Hover over a circle to pause and show its radius
- Repack button clears and restarts with new random seeds
- Download PNG button
- Live circle count and canvas coverage percentage
## Tech
Static SPA · Tailwind CDN · Canvas/localStorage
